# Start BottleFlow

Run `npm ci`, then `npm start`. Open the app in a compatible Expo Go client or Android emulator. Tap **Try pickup demo** to rehearse the WA pickup flow with sample data.

To sign in and use live requests, copy `.env.example` to `.env`, add your Firebase app configuration, and follow the Firebase setup in the [README](README.md#1-connect-your-firebase-project). Run `npm run check:config` to verify the configuration.

The [presentation guide](docs/PRESENTATION_SCRIPT.md) has the 10-minute walkthrough. Run `npm test` and `npm run typecheck` before presenting code changes.
